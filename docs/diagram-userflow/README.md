# Dokumentasi Alur Pengguna & Diagram Sistem (User Flow & Flowchart)

Folder ini berisi bahan-bahan perancangan antarmuka dan alur interaksi pengguna untuk proyek website **Yayasan Pendidikan Islam (YPI) Mutiara Ilmu Papakserang (Tarbiyatul Qur'an)**:

1. **Userflow dan Flowchart-New flowchart.drawio.png**: Gambaran menyeluruh peta alur pengguna baru pada website yayasan.
2. **Userflow dan Flowchart-Skenario 1.drawio.png**: Skenario 1 - Penjelajahan informasi profil yayasan, akreditasi, dan legalitas resmi Kemenkumham & Kemenag RI.
3. **Userflow dan Flowchart-Skenario 2.drawio.png**: Skenario 2 - Galeri kegiatan santri, cerita santri berprestasi, dan filter kategori unit (RA, DTA, Majelis Ta'lim).
4. **Userflow dan Flowchart-Skenario 3.drawio.png**: Skenario 3 - Alur donasi/infaq, salin rekening otomatis 1-klik, dan konfirmasi WhatsApp langsung ke pengurus.
5. **user_ss_3.png**: Tangkapan layar referensi evaluasi antarmuka.
